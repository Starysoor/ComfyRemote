# Iris · 灵瞳 v2.3.0

**多云模型与创作项目更新 / Multi-provider cloud & creative workspace**

- **云端扩展**：加入 OpenAI、Gemini、Replicate、SiliconFlow、AutoDL Models，以及自定义 OpenAI 兼容接口和 JSON 模板。
- **分镜与素材**：支持项目素材、语义参考图、多图输入、镜头排序与尾帧衔接。
- **AI 创作工具**：增强多图视觉理解、提示词技能与模型参数控制；新增镜头式启动动画。
- **稳定性**：修复云端参数提交、任务重启恢复、取消状态、素材引用和密钥回退问题；通过 CI 与 Android 34 模拟器启动/重启测试。

**安装 / Install:** 下载下方 `Iris-v2.3.0.apk`。包名保持 `com.comfyremote.app`，支持覆盖升级。

**提示 / Notes:** 云端 API 费用和模型可用性以厂商为准。远端已接受任务后若恰遇本地存储故障，仍可能无法自动恢复；出现错误时先核对远端任务，避免重复提交。
