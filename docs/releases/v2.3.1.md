# Iris · 灵瞳 v2.3.1

**云端工作台与分镜闭环更新 / Cloud workspace & storyboard loop**

- **云端工作台**：创作页新增厂商卡片，模型按厂商分组；可单独关闭某个厂商，关闭后其模型、最近预设和最近结果都会隐藏。
- **模型真实拉取**：OpenAI、Gemini、Replicate、SiliconFlow、AutoDL Models 的模型列表改为从厂商接口拉取，不再使用内置预设；支持清空模型与断开厂商配置。
- **参考图能力**：GPT Image、Gemini 图片、Seedream、SiliconFlow 编辑/I2V 等模型会显示真实可用的参考图上传槽；OpenAI 编辑走 multipart `/images/edits`，Gemini 使用 inline image parts。无法使用参考图的模型不会显示上传框。
- **厂商归属修复**：确认弹窗、计费说明、生成页副标题和错误信息都会显示实际厂商，不再把其他厂商请求误导向 AutoDL。
- **分镜工作台**：尾帧接力改为可选的整项目玩法，可在新建项目时选择、在项目中随时开关；关闭后只清除自动继承的参考图。
- **分镜结果闭环**：每个镜头完成后，尾帧会自动进入项目素材和 Results；视频尾帧会在 History 中保留独立副本，旧项目会自动迁移一次。镜头卡片分别展示结果和尾帧，并新增“使用上一镜尾帧”操作。
- **稳定性修复**：删除尾帧素材不再破坏下一镜的自动参考；项目重新加载时会按接力开关重建尾帧链；镜头重排后尾帧素材名称保持正确。

**安装 / Install:** 下载下方 `Iris-v2.3.1.apk`。包名保持 `com.comfyremote.app`，支持覆盖升级。

**提示 / Notes:** 云端模型和计费规则以各厂商为准；关闭厂商只会隐藏其模型，不会删除本地结果或已下载素材。
