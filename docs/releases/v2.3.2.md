# Iris · 灵瞳 v2.3.2

**多云模型 · 生成安全与恢复 · Tailscale 设备发现**

本次版本将已合并 PR #40 的多云功能、数据完整性修复和连接改进正式发布。

### 新增与改进

- **多云模型与参考图**：本地 ComfyUI 和 OpenAI、Gemini、Replicate、SiliconFlow、AutoDL Models、自定义兼容接口共存；多图参考按模型的真实输入契约上传，支持图像编辑、视频与音频等场景。
- **任务可靠性**：本地任务取消必须成功持久化后才报告成功；对“取消与实际开始提交”的竞态增加防护，减少用户已取消但付费请求仍被提交的风险。
- **历史与分镜保护**：不同厂商/服务器的远端任务 ID 不再互相覆盖历史文件；不安全的远端 ID 不会直接作为本地文件路径；任务被删除或淘汰时，分镜能进入提示性的可恢复状态。
- **导入安全**：图片和音频导入增加大小限制，音频采用流式写入；避免超大媒体导致内存耗尽。
- **Tailscale 发现**：保留局域网/VPN 网段及已保存 ComfyUI 服务器的扫描。新增**可选**的只读 Tailscale 设备列表发现：在连接页或服务器管理页配置 `devices:core:read` 权限的访问令牌后，可检测未保存且跨网段的 Tailnet 节点。令牌只发送给官方 Tailscale HTTPS API，不会发送给 ComfyUI 主机。
- **安全与兼容**：参考图 URL 下载不泄露云厂商 API 密钥；云模型配置升级不删除用户保存的模型 ID；连接恢复的旧请求不再覆盖新选择。

### 安装

下载本页下方的 **`Iris-v2.3.2.apk`**。包名保持 `com.comfyremote.app`，版本为 **2.3.2（versionCode 28）**，可在使用同一签名的旧版上覆盖安装。

### 测试与注意事项

- 通过 JVM 单元测试、Android Lint、Debug/Release 候选构建和 Android 34 模拟器启动/强制停止/重启 Smoke；正式发布流程另行验证已签名 APK 的包名、版本和签名。
- 测试**不代表**所有云端模型都进行过真实付费请求。API 价格、计费和支持模型请以厂商实时说明为准。
- 若远端已接受任务但本机恰好无法保存任务索引，可能需要手动使用远端 ID 找回任务；请先核对厂商任务状态，避免重复付费。
- Tailscale 设备列表仅是可能的目标，实际连接需要设备在线、Tailnet ACL/Grants 允许访问，ComfyUI 对 Tailnet 地址开放监听；未配置只读令牌时仍可手动填写 IP / MagicDNS。
- 某些设备的 Android Keystore 不可用时，应用的已有凭据库可能回退到本地明文存储。建议在安全设备上配置敏感令牌。
